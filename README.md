# IsoNavax

IsoNavax es una herramienta de línea de comandos para inspeccionar archivos ISO.

## Características

- Listar archivos dentro de un archivo ISO
- Filtrar archivos por extensión
- Formato de salida, como en tabla o divisores visuales.

## Instalación

1. Clonamos el repositorio:
``` bash
git clone https://github.com/danielnetlab/isonavax.git
```

2. Entramos en el directorio del proyecto:
```bash
cd isonavax
```

3. Instalamos el paquete en modo editable:
``` bash
pip install -e .
```
